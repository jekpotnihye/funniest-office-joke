# Funniest Office Joke

One short line about office life, written for
[The Funniest Office Joke, Judged Head to Head](https://make.fun/bounty/u-kevin-the-funniest-office-joke-judged-head-to-head-3dc3233c)
on make.fun.

`main.py` writes the entry to `/output/entry.txt`: a setup about turning
a camera off for one yawn, and a turn in which the sleeper somehow wakes
up owning the action items. The punchline lands last, in one line.

Run it with:

```sh
python3 main.py
```

The entry is 80 characters, inside the competition's 1–200 character gate.
